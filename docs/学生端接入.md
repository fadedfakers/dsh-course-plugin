# 学生端接入说明

> 这份文档给**学生**看。老师只需在群里发**课程码**和**公开仓地址**两样东西。

---

## 零、你会拿到两样东西

| 从老师那里拿到 | 例子 |
| --- | --- |
| **课程码** | `DL2026-A7K3` |
| **公开仓地址** | `https://github.com/<老师>/dl-course-public` |

课程码不是密码，它只是"配置包"—— 告诉你读哪个仓、插件用哪个版本。
**权限不在课程码里**，在仓库本身的可见性里（你只能读，不能写）。

---

## 一、拿资料（只需要 git）

```sh
git clone https://github.com/<老师>/dl-course-public
cd dl-course-public
```

先打开 `课程.json`，里面写明**已发布**了哪些课时、文件在哪。

> ⚠️ **未发布的课时在这个仓库里不存在。** 不是藏起来了，是根本没有。
> 你要的资料找不到 → 提 issue 问，不要去找"隐藏文件"。

目录约定：

| 目录 | 内容 |
| --- | --- |
| `教案/` | 已发布课时的详细教案（含学习目标与验收标准） |
| `代码示例/` | 已发布的模板与检查清单 |
| `FAQ/` | 老师审核过、已沉淀的常见问题 |
| `作业/` | 讲评后才发布的参考答案 / 优秀答案（可能为空） |

**课件 PPT 不在仓库里**，请看 B 站录播或课堂讲义。

## 二、装 AI 答疑面板（可选，但推荐）

这个面板让你**在课件/教案上框选提问、AI 即时作答、并把问题归档给老师**。

> 🔑 **关键：它跑在你自己的电脑上，用你自己的 API Key。**
> 你的 key 只存在你本机 `~/.dsh/.credentials.yaml`，不经过老师的服务器，
> 老师看不到你的 key，也看不到你**没提交**的对话。问一次的额度花的是你自己账号的钱。

### 1. 装 DSH

```sh
npm i -g @deepseek-ai/dsh
```

### 2. 装课程面板插件

```sh
# 老师会把这一行的地址发给你（本地路径、tarball 或 git 地址都行）
dsh plugin --profile web add <面板插件地址>
```

### 3. 配你自己的模型 key

```sh
dsh            # 首次运行会引导你配置 provider 与 API Key
```

key 写在 `~/.dsh/.credentials.yaml`（**不要**把它发给任何人，包括老师）。

### 4. 启动并打开

```sh
dsh web
```

浏览器打开它给的地址，侧栏底部会出现「课程问题池」图标。

### 5. 面板里能做什么

| 视图 | 用途 |
| --- | --- |
| **章节** | 切第一/二/三章，看本章课时格子 |
| **课件** | 按真实坐标还原 PPT 页面；**框选一块**（公式、截图）→ 提问 |
| **教案** | 读已发布教案；**拖选一段文字** → 提问 |
| **作业批改** | 点左侧课时 → 上传你的代码 → 让 AI **按教案**做初筛 |
| **问题池** | 看已归档的问题；可多轮追问（会带上前文） |

**注意**：AI 答复是**草稿**，供你自查用。**成绩判定由老师做**，面板不会给你打分。
作业批改只做"证据初筛"（比如教案要求你手写实现、你却直接调库绕过，它会指出来）。

## 三、提问怎么走（唯一通道：公开仓的 Issues）

**不要在群里 @ 老师然后指望被记录。** 群消息会漏，issue 不会。

流程：

1. 打开公开仓 → `Issues` → `New issue` → 选「课程提问」
2. 先搜一下有没有人问过（**包括已关闭的**），再看 `FAQ/`
3. 按模板 9 个字段填

模板里有三个字段是**刻意设计**的，请认真填：

| 字段 | 为什么重要 |
| --- | --- |
| 第 3 项「你的原始理解」 | 你用的是哪个词，说明你脑子里是哪个模型。**不要改写成教科书说法** —— 老师靠这个定位误区 |
| 第 4 项「你已经试过什么」 | 写"没试过"也比空着好；有这一步老师才知道该从哪补 |
| 第 8 项「严重度」 | 影响交作业的选「阻塞」并在标题加 `【紧急】`，会优先处理 |

### 好的提问

```
课时：课时8（损失曲面几何与优化器推导）
卡在哪：教案说"鞍点处 Hessian 有负特征值"，我不理解为什么
       负特征值就一定是鞍点而不是极大值
我试过：查了维基，但那里用二阶导矩阵的行列式，跟教案的特征值说法对不上
```

### 差的提问

- 「第 8 课看不懂」—— 老师不知道你看不懂哪一句
- 「代码报错了」—— 没有报错原文，没法判断
- 贴一整屏代码，但没说期望什么、实际得到什么

## 四、作业怎么交

以**课堂通知**为准。公开仓**不接收**作业提交。

如果你在面板里用「作业批改」自测，上传的文件：

- 类型：`.py` `.ipynb` `.md` `.txt` `.yaml` `.yml` `.json` `.csv` `.tsv`
- 上限：**4 MB**（含输出的 `.ipynb` 很容易超，交之前清一下输出）

> ⚠️ **不要上传模型权重**（`.pth` `.pt` `.ckpt` `.onnx`）。
> 它们是二进制大文件，动辄几百 MB，不属于文本交付物。
> 需要交权重时老师会另给通道（共享盘 / 对象存储）。

## 五、FAQ

**Q：面板图片全都不显示，是「图片不可用」占位框？**
A：先点「刷新」。若仍不行，这是老师端的问题（图片服务未就绪），请提 issue 说明"课件图片全部不显示"。

**Q：面板报 `加载失败：...` / 侧栏没有图标？**
A：把浏览器 **F12 → Console** 里 `[course-panel]` 开头的报错原文贴进 issue。

**Q：我需要装什么？**
A：只要资料 → 只用 git。要用 AI 答疑 → 再加 DSH + 面板插件（第二节）。

**Q：我的 API Key 会被老师看到吗？**
A：不会。它只在你的机器上，面板是本地的。

**Q：能把我看到的资料转发出去吗？**
A：不能。教案与代码属于课程材料。

**Q：为什么有用的资料没发布？**
A：公开发布是老师**逐项显式勾选**的，不是自动同步。你认为某份该公开，提 issue 说明理由——这是有效反馈。

## 六、出问题时的最小信息包

提 issue 时带上这四项，能省一轮来回：

1. 你用的是哪个视图（章节/课件/教案/作业批改/问题池）
2. 你点了什么、期望什么、实际看到什么
3. F12 Console 里的报错原文（`[course-panel]` 开头）
4. `dsh --version` 和插件地址（若与 AI 答疑相关）

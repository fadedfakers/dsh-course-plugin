# 鼹鼠仔 · 课程资料（学生端）

这个仓库存放**老师已经发布**的课程资料，以及学生端面板插件。
没有发布的课时，在这里是**不存在的**——不是藏起来，是根本没有。

---

## 一、你能在这里看到什么

| 目录 | 内容 |
| --- | --- |
| `课程.json` | 已发布内容的清单（哪些课时有资料、路径在哪）。**先看这个。** |
| `教案/` | 已发布课时的详细教案（含学习目标与验收标准） |
| `课程中心/` | 课程结构索引与课件数据（面板读的就是这份） |
| `公开问答.json` | 老师审核后公开给全班的问题索引 |
| `panel/` | 学生端面板插件（`dsh-course-student` + 共享内核 `dsh-course-core`） |
| `FAQ/` | 已沉淀的常见问题（老师审核过才会出现在这里） |

`课程.json` 里的 `publishedLessons` 告诉你当前发布了几课时。
**如果你要的课时不在清单里，说明老师还没发布** —— 在面板里问一句就行，
不要去找「隐藏文件」，没有隐藏文件。

## 二、怎么提问（用面板，不用 Issues）

装好面板（见第四节）之后，所有提问都在**面板里**完成：

```
课件页 → 框选一块（公式/图表/讲义截图都行）→ 写问题 → 提交
```

提交后会依次发生三件事：

1. **凝练标题**：模型把你的问题压成一句统一风格的标题（长问题也能一眼看懂）
2. **AI 作答**：基于你框的那块内容和教案作答
3. **生成问题总结**：两三句话说明这条问题在问什么

### 你的问题默认只有你能看到

这是刻意的设计，不是限制：

- 你的提问落在**你自己电脑上**的私有目录里，别人看不到
- **老师也看不到** —— 除非你在「我的提问」里点「公开给老师」
- 老师看到并答复后，如果他判断这条对全班有价值，会把它公开给全班

**为什么要你手动公开**：一次作业批改会判出十几条问题，如果全自动推给老师，
他一天要面对几百条，最后只能不看。让他只看你主动送上来的那几条，
每一条才会被认真看。**选择权在你手上，这是为了让你的问题真的被回答。**

### 好的提问长什么样

- 说清**卡在哪一句**：「教案里说鞍点处 Hessian 有负特征值，我不理解为什么负特征值
  就一定是鞍点而不是极大值」
- 说清**你试过什么**：「查了维基，但那里的判据说要用二阶导矩阵的行列式，
  跟教案里的特征值说法对不上」
- 报错就**把报错原文贴上来**（可以直接 Ctrl+V 粘贴截图）

### 差的提问

- 「第 8 课看不懂」—— 不知道你看不懂哪一句
- 「代码报错了」—— 没有报错原文，没法判断
- 贴一整屏代码但没说期望什么、实际得到什么

## 四、关于 AI 答疑：用你自己的 API

**重要：这个面板跑在你自己电脑上，用你自己的 API Key。**

- 你的 Key 只存在你本机（`~/.dsh/.credentials.yaml`）
- 提问消耗的是**你自己的额度**，不经过老师的服务器
- 老师看不到你的 Key，也看不到你没公开的对话

### 一键安装（推荐）

在本仓根目录打开 PowerShell，跑一条就够：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

它会依次做这些事：

1. 确认本仓完整（课程数据与插件都在）
2. 检查 Node.js（>= 20）
3. 检查 DSH，没装就装
4. 从**本仓自带的** `panel/dsh-course-student` 与 `panel/dsh-course-core` 安装面板插件
   （学生端 + 共享内核两个包；教师端那个包在老师机器上，你不用装）
5. 把「课程工作区」指向你 clone 下来的这个目录，并说明你的学生身份名
6. 指引你配置自己的 API Key，然后启动

**想先看它要做什么、不实际改动**：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -DryRun
```

脚本**不下载任何第三方代码**，只调用 `npm` 和 `dsh`。插件就在本仓 `panel/` 下，
是纯文本 JS，你可以自己打开逐行看它做了什么。

### 拿到老师新发布的内容

老师在老师机上把新内容推上来之后，本机这份不会自动更新。在面板顶部点
**「刷新」旁的同步入口**（或「公开问答」页的拉取按钮），它会做一次
`git pull --ff-only` —— 只快进合并，不产生 merge commit，
**绝不会碰你自己的提问**（它们在 `.gitignore` 里）。

## 五、关于作业

作业就在面板里交，**不用另外发邮件或传文件给老师**：

```
左侧课时脉络 → 点一个课时 → 「我的提交」→ 写/传/拍 → 提交并批改
```

支持三种方式，可以组合：

| 方式 | 适合什么 |
| --- | --- |
| **打字** | 推导过程、实验结论、设计说明；手推公式可以用文字/符号写 |
| **文件** | `.py` / `.ipynb` / `.md` / `.pdf` / `.zip` 等，单个 ≤ 8 MB，最多 6 个 |
| **图片** | 选图片，或**直接 Ctrl+V 粘贴截图**；也可以从课件上框一块收进来 |

AI 会**按教案逐条对照**批改，每条结论都带证据。它判出的问题**默认不公开**，
你可以去「我的提问」里挑要公开给老师的。

**每一次提交都是一个新版本**，旧版和旧版的批改都保留 —— 改完再交一版即可，
不会覆盖。面板顶栏的「提交历史」里能看到全部版本（与课时无关，按时间倒序）。

## 六、什么内容会被公开（以及为什么有些不会）

公开发布是**老师显式勾选**的结果，不是自动同步。以下内容**默认不公开**：

- 未定稿的教案与草稿
- 其他同学的原始提问与作业
- 评分维度与批改细节（公开与否属于教学决定）
- 课堂录音、录播源文件

你自己的提问**默认也不公开**，要你手动选择才会给老师看（见第二节）。

如果你认为某份资料应该公开但没有，**在面板里问一句**，比在群里问更不容易漏掉。

## 七、请不要做的事

- 不要把本仓库内容转发到公开平台（课件与教案属于课程材料）
- 不要在公开的地方贴自己的 API Key、密码、学号全号
- 不要手动改 `课程中心/_插件源码/` 与 `panel/` 下的文件后不说明 ——
  那些是插件本体，改了会与老师那份不一致，出问题时很难判断是谁改的

## 八、出问题了怎么办

| 症状 | 先做什么 |
| --- | --- |
| 面板显示「未知动作：xxx」 | 宿主半区没重启。关掉重开一次 |
| 打开诊断页自查 | 浏览器访问 `http://127.0.0.1:3080/cip-stu-diag/` |
| 作品图片/公式显示不出来 | 检查 `课程中心/预览数据/media/` 下有没有对应图 |
| 数据像是旧的 | 删掉 `课程中心/.cache` 后刷新（那只是缓存，删了会重算） |
| 同步拉不到更新 | 你可能改过本仓的文件导致不能快进合并；先 `git status` 看一眼 |

提问里带上**诊断页的截图**，老师能直接定位。

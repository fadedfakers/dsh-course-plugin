> 这份文档给**学生**看。老师只需在群里发**课程码**和**公开仓地址**两样东西。

| 从老师那里拿到 | 例子 |
| --- | --- |
| **课程码** | `DL2026-A7K3` |
| **公开仓地址** | `https://github.com/<老师>/dl-course-public` |

## 一、拿资料（只需要 git）

```sh
git clone https://github.com/<老师>/dl-course-public
cd dl-course-public
```

先打开 `课程.json`，里面写明**已发布**了哪些课时、文件在哪。

> ⚠️ **未发布的课时在这个仓库里不存在。** 不是藏起来了，是根本没有。
> 你要的资料找不到 → 在面板里问一句（见下方「怎么提问」），不要去找"隐藏文件"。

目录约定：

| 目录 | 内容 |
| --- | --- |
| `教案/` | 已发布课时的详细教案（含学习目标与验收标准） |
| `代码示例/` | 已发布的模板与检查清单 |
| `FAQ/` | 老师审核过、已沉淀的常见问题 |
| `课程中心/` | 课件数据：`课程结构索引.json` + `预览数据/<章>.json` + 课件图片。**面板读的就是这里** |
| `panel/` | 面板插件本体 —— **三个包**：`dsh-course-student`（你要装的）、`dsh-course-core`（共享内核，也要装）、`dsh-course-teacher`（老师那边用的，你不用装）。都是纯文本 JS，可以自己打开看 |

> `课程问题池/`、`作业提交/` 是安装后由面板在你本机创建的，`.gitignore` 已忽略 ——
> 里面只有你自己的提问、AI 给你的回答、你交的作业，**不会**被提交。

## 二、装 AI 答疑面板（可选，但推荐）

这个面板让你**在课件/教案上框选提问、AI 即时作答、并把问题归档给老师**。

> 🔑 **关键：它跑在你自己的电脑上，用你自己的 API Key。**
> 你的 key 只存在你本机 `~/.dsh/.credentials.yaml`，不经过老师的服务器，
> 老师看不到你的 key，也看不到你**没提交**的对话。问一次的额度花的是你自己账号的钱。

### 最快路径：一键装置

在本仓根目录打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

它把下面 1–5 步全做完，另外还会：
把「课程工作区」指向你 clone 下来的这个目录（面板靠它找到课件与你的提问记录），
并告诉你当前用的学生身份名。

想先看它要做什么：加 `-DryRun`。

脚本不下载任何第三方代码，只调用 `npm` 和 `dsh`；插件就在本仓 `panel/` 下，
是纯文本 JS，你可以自己打开逐行看。

**如果一键装置失败，或你想自己一步步来**，见下面 1–5 步。

### 1. 装 DSH

```sh
npm i -g @deepseek-ai/dsh
```

> 装完如果在终端敲 `dsh` 说「不是内部或外部命令」，**不代表没装成功** ——
> npm 的全局 bin 链接在某些环境下不会生成。本仓的 `start.ps1` 会自己去找真实入口，
> 所以直接用那个脚本启动就好，不必手动修 PATH。

### 2. 装课程面板插件

学生端与共享内核是**两个包，都要装**。教师端那个包你不用装 —— 它是老师机器上的另一个插件。

```sh
# 在本仓根目录执行；插件就在本仓里，不需要联网
dsh plugin --profile web add .\panel\dsh-course-student
dsh plugin --profile web add .\panel\dsh-course-core
```

> ⚠️ **两个包必须留在 `panel/` 下的原位。** 内核是按「相对本包位置算出的绝对路径」
> 装载的，你把某个包单独挪走，启动时就会找不到它；而那个报错发生在 DSH 启动阶段，
> 看起来像 DSH 本身坏了。

### 3. 把课程工作区指向本仓

面板要找到课件和你的提问记录，必须知道「课程工作区」在哪。写一个配置文件告诉它：

```powershell
# 把 <本仓的绝对路径> 换成你 clone 下来的实际位置
"<本仓的绝对路径>" | Out-File -Encoding utf8 "$env:USERPROFILE\.dsh\cip-workspace.txt"
```

或者设环境变量 `CIP_WORKSPACE`（优先级更高）。

### 4. 配你自己的模型 key

```sh
dsh            # 首次运行会引导你配置 provider 与 API Key
```

key 写在 `~/.dsh/.credentials.yaml`（**不要**把它发给任何人，包括老师）。

### 5. 启动并打开

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

浏览器打开它给的地址，侧栏底部会出现「课程问题池」图标。

### 面板里能做什么

| 视图 | 用途 |
| --- | --- |
| **章节** | 切第一/二/三章，看本章课时格子 |
| **课件** | 按真实坐标还原 PPT 页面；**框选一块**（公式、截图）→ 提问 |
| **我的提问** | 看你自己归档的提问；**可以一直追问**，每一轮都会真的调模型作答 |
| **公开问答** | 老师审核后公开给全班的问题（含问题总结、哪些有教师答复） |
| **作业批改** | 选课时 → 传代码 → 让 AI **按教案**做初筛 |
| **额度** | 你累计消耗的 tokens —— 提问、追问、批改都算你的 |

你是**学生端**，面板标题旁会显示「学生」徽标。

**关于「公开问答」**：老师审过的问题会随仓库发到这里，你能看到完整问答与总结。
这份清单只含老师明确公开的 —— 别的同学私有的提问不在其中，也不会出现在仓库的任何地方。

**关于教师答复**：老师可以直接答复你（不一定要先决定是否公开）。
那种答复会以「教师答复」单独显示在「我的提问」里那条提问的最前面，
和 AI 的草稿分开 —— 两者的可信度不是一个级别。列表里也会标「教师已答复」。

**注意**：AI 答复是**草稿**，供你自查用。**成绩判定由老师做**，面板不会给你打分。

## 三、提问怎么走（唯一通道：公开仓的 Issues）

**不要在群里 @ 老师然后指望被记录。** 群消息会漏，issue 不会。

流程：

1. 打开公开仓 → `Issues` → `New issue` → 选「课程提问」
2. 先搜一下有没有人问过（**包括已关闭的**），再看 `FAQ/`
3. 按模板 9 个字段填

模板里有三个字段是**刻意设计**的，请认真填：

| 字段 | 为什么重要 |
| --- | --- |
| 第 3 项「你的原始理解」 | 你用的是哪个词，说明你脑子里是哪个模型。**不要改写成教科书说法** —— 老师靠这个定位误区 |
| 第 4 项「你已经试过什么」 | 写"没试过"也比空着好；有这一步老师才知道该从哪补 |
| 第 8 项「严重度」 | 影响交作业的选「阻塞」并在标题加 `【紧急】`，会优先处理 |

### 好的提问

```
课时：课时8（损失曲面几何与优化器推导）
卡在哪：教案说"鞍点处 Hessian 有负特征值"，我不理解为什么
       负特征值就一定是鞍点而不是极大值
我试过：查了维基，但那里用二阶导矩阵的行列式，跟教案的特征值说法对不上
```

### 差的提问

- 「第 8 课看不懂」—— 老师不知道你看不懂哪一句
- 「代码报错了」—— 没有报错原文，没法判断
- 贴一整屏代码，但没说期望什么、实际得到什么

## 四、作业怎么交

以**课堂通知**为准。公开仓**不接收**作业提交。

如果你在面板里用「作业批改」自测，上传的文件：

- 类型：`.py` `.ipynb` `.md` `.txt` `.yaml` `.yml` `.json` `.csv` `.tsv`
- 上限：**4 MB**（含输出的 `.ipynb` 很容易超，交之前清一下输出）

> ⚠️ **不要上传模型权重**（`.pth` `.pt` `.ckpt` `.onnx`）。
> 它们是二进制大文件，动辄几百 MB，不属于文本交付物。
> 需要交权重时老师会另给通道（共享盘 / 对象存储）。

## 五、FAQ

**Q：面板图片全都不显示，是「图片不可用」占位框？**
A：先点「刷新」。若仍不行，请提 issue 说明「课件图片全部不显示」，并附上
面板「章节」页顶部那行状态（它会显示工作区路径与图片服务状态）。

**Q：面板打开了但是空的 —— 一条问题没有、课件 0 页？**
A：多半是**课程工作区没指对**。检查 `%USERPROFILE%\.dsh\cip-workspace.txt`
里那一行是不是本仓的绝对路径，且该目录下确实有 `课程中心\` 子目录。
改完重启面板（关掉再跑 `start.ps1`）。

**Q：面板报 `加载失败：...` / 侧栏没有图标？**
A：把浏览器 **F12 → Console** 里 `[course-panel]` 开头的报错原文贴进 issue。

**Q：我需要装什么？**
A：只要资料 → 只用 git。要用 AI 答疑 → 再加 DSH + 面板插件（第二节）。

**Q：我的 API Key 会被老师看到吗？**
A：不会。它只在你的机器上，面板是本地的。

**Q：能把我看到的资料转发出去吗？**
A：不能。教案与代码属于课程材料。

**Q：为什么有用的资料没发布？**
A：公开发布是老师**逐项显式勾选**的，不是自动同步。你认为某份该公开，提 issue 说明理由——这是有效反馈。

## 六、出问题时的最小信息包

提 issue 时带上这四项，能省一轮来回：

1. 你用的是哪个视图（章节/课件/教案/作业批改/问题池）
2. 你点了什么、期望什么、实际看到什么
3. F12 Console 里的报错原文（`[course-panel]` 开头）
4. `dsh --version` 和插件地址（若与 AI 答疑相关）
